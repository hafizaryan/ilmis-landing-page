# ILMIS Landing Page

Halaman landing (landing page) untuk ILMIS, Sistem Informasi Manajemen Laboratorium.

## Teknologi
- HTML
- CSS
- JavaScript

## Cara Menjalankan
Buka berkas `index.html` di browser, atau jalankan dengan ekstensi Live Server di editor.

Proyek terkait: repositori `sitaris` (aplikasi Sistem Informasi Inventaris Laboratorium).
